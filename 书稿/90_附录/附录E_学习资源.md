# 附录 E 学习资源与延伸阅读

> 书看完了，活干完了，接下来去哪儿找东西。

这一页只做三件事：告诉你随书的东西在哪儿拿，告诉你我在哪些平台上继续更新，告诉你想往深了学该搜什么关键词。

我不打算在这里列一堆书名和链接。原因很实在：这类清单半年就过期一半，而"搜什么关键词"能管用三年。

## E.1 随书资源

### GitHub 开源仓库

**地址**：github.com/Shun1989/Erics-WorkBuddy-Practice

开源协议：**MIT**。你可以随便用、随便改、拿去给公司用也行，唯一的要求是保留署名。

仓库里有四样东西：

| 内容 | 说明 |
|---|---|
| 72 个场景的抄作业模板 | 每个场景一套：提示词原文、检查清单、验收标准。复制就能用 |
| 30 多个 WorkBuddy 技能与工作流 | 可以直接安装，覆盖数据整理、报告生成、图纸检查、试验记录这些重复劳动最集中的环节 |
| 书中自绘示意图的 SVG 源文件 | 拿去改就能用，配色和字体都是按本书的规范排的 |
| 翻车案例库 | 每个场景的已知错误模式与排错记录 |

为什么要把这些放到公开仓库里：这本书反复讲"可复现"。一个场景如果你拿去跑不通，那它就只是故事，不是方法。仓库里的东西就是让你跑通的。

拿完之后建议做一件事：挑一个你下周真要干的活，打开对应场景的模板，把提示词里的方括号换成你的真实内容，跑一遍。跑通的那个，才是你的。

### 微信公众号「Eric的数字花园」

**回复关键词**：「实战」

回复之后可以领到：随书 72 个场景的提示词合集，以及案例用的脱敏练习素材。

公众号上持续更新的三类内容：新工具怎么接进工作流、旧方法哪里开始失灵、读者寄来的翻车现场。AI 加汽车零部件行业的交叉内容，主要发在这里。

### 汽研 Agent 中文社区

**网址**：qiyanagent.org.cn

面向汽车与制造行业的 AI 应用者社区。每天整理行业 AI 动态，积累工程场景的真实用法，也收集翻车案例。

如果你在制造业、汽车或者硬件行业，这个社区比公众号更适合你。公众号面向泛职场，社区只聊工程。

## E.3 延伸阅读方向

下面这张表不给书名，给方向。每个方向告诉你该搜什么关键词、该看哪一类资料。原因是这类领域半年一变，记住关键词比记住书名划算。

### E.3.1 AI 基础

| 方向 | 搜什么关键词 | 看哪类资料 |
|---|---|---|
| 模型到底在干什么 | 大语言模型原理、预测下一个词、注意力机制 | 找带图解的科普文章或公开课，别一上来就看论文 |
| 它为什么会编 | 幻觉、Hallucination、知识边界 | 找讲"模型不知道自己不知道"的分析文章 |
| 能力边界在哪 | 模型评测、Benchmark、能力对比 | 找第三方评测报告，看它在哪类任务上掉得快 |
| 上下文是怎么工作的 | 上下文窗口、Context Window、长文本 | 找讲"为什么聊久了它会忘"的技术博客 |
| 成本是怎么算的 | Token 计费、输入输出计费 | 直接看各家官方文档的计费说明页 |

## E.4 怎么持续跟得上

这个领域变化快到让人焦虑。我用下来有效的就三条，都不花什么力气。

**第一条，关注一个会持续更新的源。**

公众号或者社区，选一个就够。挑的标准不是内容多，是它会不会讲"这个以前管用的方法现在不管用了"。只讲新工具不说旧方法失灵的源，看着热闹，实际帮不上忙。

**第二条，进一个只聊工程场景的社区。**

泛职场 AI 社区的问题是，里面大量内容跟你的活没关系。找一个你所在行业的社区，大家说的都是同一类活，翻车案例能直接对上号。汽研 Agent 中文社区就是为这个建的。

**第三条，自己建一个案例库。**

这条最笨，也最有用。每次你用 AI 干成一件活，或者干砸一件活，花五分钟记三样东西：提示词原文、产物、验收结论。三个月之后你会有一份只属于你的资料，它的价值超过你读过的任何一份别人的清单。

我在第 21 章讲过团队怎么建库，这里说的是个人版：一个文件夹，一个固定格式的文件名，一条记录五分钟。
